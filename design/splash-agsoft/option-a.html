AgSoft · developer splash · option A

Struck silver: an element tile that softens under the hammer

Concept

A periodic-table tile for silver: 47 · Ag · Silver · 107.87 (from Latin argentum). The outline is traced like an instrument calibrating while the atomic number counts up to 47. A metallic sheen crosses the tile, with a hair-thin pink/cyan dispersion fringe that nods to the Quantum palette. Then the tile is struck: it squashes, springs back, its corners round off and the “Ag” glyphs swell and soften. The softened tile slides left and “Soft” slides out from behind it, so the tile itself spells [Ag]Soft. Hold, then fade to #0a0612, the welcome screen's background.

Wordplay

AgSoft = “soft Ag”. Silver is a soft, malleable metal (Mohs hardness ≈ 2.5, it can be beaten into leaf), so the logo is worked like metal, not melted. The symbol “Ag” keeps its real Latin origin, shown in the tagline (argentum). Everything on the tile is factual: atomic number 47, standard atomic weight 107.87.

Android implementation

  • Phase 1, system splash (Android 12 SplashScreen API, androidx.core:core-splashscreen for minSdk 26): windowSplashScreenBackground = #0a0612, windowSplashScreenAnimatedIcon = an AnimatedVectorDrawable of the tile (outline trimPathEnd 0→1 then fill alpha, about 600 ms). Glyphs are exported as vector paths (Fira Sans and JetBrains Mono are OFL). API 26–30 shows the static tile. The tile fits inside the 160 dp safe circle of the 240 dp icon mask (preview below).
  • Phase 2, Compose (setOnExitAnimationListener hands over to an AgSoftSplash() composable that starts on the same frame and at the same position): a single Canvas. The sheen is a translated Brush.linearGradient inside clipPath. The strike is graphicsLayer scale with a spring() pivoted at the bottom edge. The softening is the glyph path drawn twice, fill plus Stroke(width, join = StrokeJoin.Round) with an animated width (the same trick as this mockup), plus an animated corner radius. “Soft” is revealed with clipRect. The count-up is done in phase 2 only (an AVD cannot draw changing text), so the AVD shows “47” straight away.
  • Budget: about 2.45 s in total (AVD ≈ 0.6 s + Compose ≈ 1.85 s). Cold start only, tap to skip. About 6 KB AVD plus 4 KB of path data, no bitmap, no video, no RenderEffect/blur. One radial “bloom” gradient drawn once (so no extra bloom pass), under 20 draw calls per frame. prefers-reduced-motion maps to Settings.Global.ANIMATOR_DURATION_SCALE == 0: show the still logo for 600 ms, then cut.
