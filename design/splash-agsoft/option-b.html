AgSoft · developer splash · option B

Quicksilver drop: water-silver settles into soft silver

Concept

A single quicksilver drop falls onto the dark screen, stretched by its speed. It splashes into a puddle; thin dotted ripples spread and a few droplets leap and fall back. The liquid then gathers and rises into a square, wobbles like jelly and sets into a crisp element tile. For a beat the tile reads 80 · Hg · Mercury · 200.59, then it “recalibrates” like an instrument to 47 · Ag · Silver · 107.87. One bead of quicksilver stays on the corner. The AgSoft wordmark fills from below behind a wavy liquid level. Hold, then fade to #0a0612.

Wordplay

Quicksilver is mercury (Hg, 80), a metal that is liquid at room temperature. Its symbol comes from Latin hydrargyrum, from Greek hydrargyros, “water-silver”. Silver itself is Ag, 47, from Latin argentum, and it is a soft metal: “soft Ag”, AgSoft. The Hg → Ag flip is an alchemist's wink, not chemistry: mercury never turns into silver. The two metals only share the word “silver”. The tagline plays on the idiom in both languages: EN “quicksilver at heart”, FR “du vif-argent dans les veines” (vif-argent is French for quicksilver and for a lively person).

Android implementation

  • Phase 1, system splash (Android 12 SplashScreen API, androidx.core:core-splashscreen for minSdk 26): background #0a0612 with a transparent icon, so the drop can fall from above the icon mask, which it could not do inside the 240 dp circle. This costs a blank dark frame during cold start, and the frame is the welcome screen's colour anyway.
  • Phase 2, Compose (setKeepOnScreenCondition until the first frame, then AgSoftSplash()): one Canvas. The liquid is not a blur filter (the SVG “goo” here is a mockup shortcut; RenderEffect is API 31+ and costly). Instead it is 4 keyframed shapes with the same number of cubic points (drop, puddle, blob, rounded tile), interpolated point by point into a Path. Droplets are drawCircle on parabolas that shrink as they land. Ripples are drawOval(style = Stroke(0.75.dp, pathEffect = dashPathEffect)). The tile switches to the crisp vector tile once it has settled. The Hg → Ag roll is two glyph-path groups under clipRect with a vertical offset. The wordmark fill is a clipPath built from a sine-wave Path.
  • Budget: about 2.5 s in total, cold start only, tap to skip. About 8 KB of path data, no bitmap, no video, no blur. One radial “bloom” gradient drawn once, about 30 draw calls per frame at peak (5 droplets, 3 ripples), and every Path is reused (no allocation per frame). Reduced motion (ANIMATOR_DURATION_SCALE == 0) shows the still logo for 600 ms, then cuts.
